# 03 — SRPG

FFT 풍 쿼터뷰/아이소메트릭 SRPG. 첫 마일스톤은 **위 + 턴제 전투 한 판**까지.

## 학습 포인트

- 아이소메트릭 좌표 변환 (그리드 ↔ 화면)
- BFS로 이동범위/경로 계산
- 턴 매니저 / 페이즈 전환
- 단순 AI (가장 가까운 적에게 접근 → 공격)

## 조작 (예정)

| 입력 | 동작 |
|------|------|
| WASD / 화살표 | 커서 이동 |
| Space / Enter | 선택·확정 |
| Esc / X | 취소 |
| F6 | 턴 종료 |
| 마우스 좌클릭 | 셀 선택 |

## 진행 단계

1. 스캐폴드
2. 아이소메트릭 격자
3. 커서 (키보드/마우스)
4. 유닛 배치
5. 이동범위 표시 (BFS)
6. 유닛 이동
7. 턴 시스템
8. 공격/데미지
9. 적 AI
10. 승패 판정
11. 공격 UX 개선 (적 셀 직접 선택 → 이동+공격 한 번에)
12. 마우스 클릭 입력 + 다이아몬드 셀 검출 수식 수정
13. 전투씬 분리 (battle.tscn) + 타이틀 화면 (main.tscn)

## 씬 구조

- `res://main.tscn` — 타이틀 화면. 시작 시 로드.
- `res://battle.tscn` — 전투씬. 타이틀에서 Space/Enter/클릭으로 진입.
